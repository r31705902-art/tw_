Thoughts

Defining the Project

I've got a grasp on the project's essence; it's a 3D voxel sandbox survival game called "Earthbound" (internally, "Earthbound Indev 0.95"). The focus is clearly on open-world exploration and survival within a voxel-based landscape.

Clarifying the Tech Stack

I'm now diving into the technical aspects. The project, currently codenamed "Earthbound Indev 0.95," is built with C# (.NET 8.0) and uses a custom low-level 3D engine based on OpenTK 4.9.4, acting as an OpenGL 4.x wrapper. I'm focusing on how the voxel-based world with chunk generation, blocks, climate, crafting, mobs, lighting, physics, and multiplayer elements all mesh together within this architecture. The game might share EarthBound/Mother3 musical elements, identified as NOST.

Analyzing the Asset Pipeline

I'm currently focused on the asset pipeline. For handling 3D models, I'm using StbImageSharp for PNG textures and SharpGLTF.Core to load .glb files like milstone.glb and mortar_and_pestle.glb. The sound engine leverages OpenAL.NETCore for 3D sound positioning and NVorbis to decode OGG Vorbis audio. Auxiliary Python scripts like atlas.py, wav-ogg.py, and others streamline processes like texture atlas generation, audio conversion (via ffmpeg), and procedural pixel texture modification (32x32).

I'm also reviewing the codebase, especially the auxiliary scripts. The entry point, Program.cs, uses a custom DualWriter to capture and log console output into files named like log_PID_DD_MM_YYYY_HH.

Examining Game Logic

I'm now deeply involved in the game logic, focusing specifically on Game.cs. It's the primary window and game loop controller, inheriting from GameWindow. I'm analyzing the management of game states (MainMenu, Playing, InventoryOpen, etc.), tick rate (TPS), skybox rendering, weather rendering, the WindSimulationEngine, optimization (HZBManager), and particle effects. Additionally, I'm examining the World folder which handles voxel world generation and division into chunks using Perlin/Simplex noise, and managing biomes and climate.
